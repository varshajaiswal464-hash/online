# Online Music Gallery
# About:-
Online Music Gallery is a simple website where users can listen to songs easily.
The website has a list of music artists on the home page. When a user clicks on any artist name, it opens a new page where the song is played using an audio player.
This project is designed with a clean and simple layout so that users can easily navigate between pages and enjoy music without confusion.
It is created using HTML and CSS, and it helps beginners understand how to link pages, create lists, and play audio in a website.
Overall, this project shows how to build a basic music website with artist selection and song playing features.
# Technologies Used
## Front End Technology:- HTML,CSS,BOOTSTRAP
### BackEnd :- MYSQL
#### Server Side Script:- PHP
##### Client Side Script:-Java Script,Angular JS
